Overview

This page highlights my GNSS navigation and estimation coursework, focused on implementing end-to-end positioning pipelines from raw GNSS measurements. The project uses a short kinematic dataset collected by two closely-spaced receivers (a reference antenna and a user antenna) and applies five positioning methods of increasing complexity.

Problems 1–3 solve for the relative baseline (user vs. reference) using differential pseudorange/carrier techniques and filtering. Problems 4–5 solve for the absolute position of the user antenna using stand-alone GPS methods and error-mitigation techniques.

GNSS Estimation — Differential & Stand-alone Positioning

Differential pseudorange Hatch smoothing Kalman filter Double difference LAMBDA ambiguity fixing Single-point positioning SNR weighting

The goal of this project was to implement five GNSS positioning methods and compare how accuracy improves as additional modeling and filtering are introduced. The dataset includes two receivers: Antenna 1 (reference) and Antenna 2 (user). Using broadcast ephemerides and RINEX observations, I built pipelines that estimate either (i) the relative baseline between receivers or (ii) the absolute position of the user receiver without any reference antenna.

Parts 1–3: Differential baseline (relative positioning)

  • Part 1: epoch-by-epoch least squares from single-difference code pseudoranges.
  • Part 2: Hatch smoothing + constant-velocity Kalman filter in ENU.
  • Part 3: high-accuracy differential solution using double-difference code + carrier phase, joint ambiguity estimation, and integer fixing (LAMBDA).

Figures on this page will show the ENU baseline scatter/ellipsoids and time histories for each part.

Parts 4–5: Stand-alone position (absolute positioning)

  • Part 4: GPS-only single-point positioning (SPP) using iterative nonlinear least squares.
  • Part 5: stand-alone improvements using carrier smoothing and SNR-based weighting to reduce measurement noise.

Figures will show LLH stability vs. time, estimated precision, and ENU residuals relative to truth/reference.

Part-by-part Results (figures to be added)

I’ll add figures in the same style as the project slides (ellipsoid plots, ENU components with error bounds, etc.).

Part 1 — Differential pseudorange (single-difference LS)

Solved the relative ENU baseline between the two antennas using epoch-by-epoch least squares on single-difference pseudoranges. This provides a baseline performance reference before smoothing and filtering.

  • Planned figures: p1_ellipsoid, p1_ENU_with_error

Part 2 — Hatch smoothing + ENU Kalman filter

Reduced pseudorange noise by applying carrier-aided Hatch smoothing, then used a constant-velocity Kalman filter in ENU to stabilize the baseline estimate over time.

  • Planned figures: p2_ellipsoid, p2_ENU_with_error

Part 3 — Double-difference code + carrier phase (ambiguity fixing)

Implemented a high-accuracy differential solution using double-difference code and carrier phase in an ECEF constant-velocity Kalman filter. Estimated float ambiguities and applied LAMBDA integer ambiguity resolution to obtain a fixed baseline.

  • Planned figures: p3_ellipsoid, p3_ENU_with_error

Part 4 — Stand-alone GPS single-point positioning (SPP)

Computed the absolute position of the user antenna using GPS-only pseudoranges and broadcast ephemerides. Solved for receiver position + clock bias via iterative nonlinear least squares at selected epochs and averaged across time.

  • Planned figures: p4_LLH_time, p4_clock_bias, p4_ENU_error

Part 5 — Stand-alone improvements (smoothing + weighting)

Improved stand-alone positioning by applying carrier-phase smoothing and SNR-based measurement weighting. This reduced scatter relative to raw SPP and emphasized higher-quality measurements during the LS updates.

  • Planned figures: p5_LLH_time, p5_clock_bias, p5_ENU_error

My Role

What I implemented end-to-end (from GNSS data handling to estimation and performance evaluation).

End-to-end GNSS processing & estimation

  • Data handling: parsed and synchronized RINEX observations across two receivers and filtered usable epochs/satellites.
  • Modeling: implemented pseudorange + carrier measurement models in ENU/ECEF, including differencing strategies.
  • Estimation: built LS solvers, Kalman filters, and ambiguity estimation/fixing workflow for high-accuracy baseline solutions.
  • Evaluation: compared solutions across methods using ENU/LLH outputs, precision estimates, and RMS error summaries.
