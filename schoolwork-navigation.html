Overview

This page highlights my GNSS navigation and estimation coursework, focused on implementing end-to-end positioning pipelines from raw GNSS measurements. The project uses a short kinematic dataset collected by two closely-spaced receivers (a reference antenna and a user antenna) and applies five positioning methods of increasing complexity.

Problems 1–3 solve for the relative baseline (user vs. reference) using differential pseudorange/carrier techniques and filtering. Problems 4–5 solve for the absolute position of the user antenna using stand-alone GPS methods and error-mitigation techniques.

By the end of this project I gained a much stronger understanding of GPS positioning methods and estimation techniques, from basic pseudorange least-squares to differential GNSS and filtering approaches. While the final results were not perfect (especially Parts 3 and 5), implementing each method end-to-end taught me how to diagnose and improve navigation solutions by validating models, checking coordinate-frame handling, and using RMS/error trends to identify performance limits. Overall, this project gave me practical experience turning GNSS theory into working, testable code.

Course Final Project

GNSS Estimation: Differential & Stand-alone Positioning

Differential pseudorange Hatch smoothing Kalman filter Double difference LAMBDA ambiguity fixing Single-point positioning SNR weighting

The goal of this project was to implement five GNSS positioning methods and compare how accuracy improves as additional modeling and filtering are introduced. The dataset includes two receivers: Antenna 1 (reference) and Antenna 2 (user). Using broadcast ephemerides and RINEX observations, I built pipelines that estimate either (i) the relative baseline between receivers or (ii) the absolute position of the user receiver without any reference antenna.

Parts 1–3: Differential baseline (relative positioning)

  • Part 1: epoch-by-epoch least squares from single-difference code pseudoranges.
  • Part 2: Hatch smoothing + constant-velocity Kalman filter in ENU.
  • Part 3: high-accuracy differential solution using double-difference code + carrier phase, joint ambiguity estimation, and integer fixing (via the LAMBDA method).

Figures on this page show the ENU baseline scatter/ellipsoids and time histories for each part.

Parts 4–5: Stand-alone position (absolute positioning)

  • Part 4: GPS-only single-point positioning (SPP) using iterative nonlinear least squares.
  • Part 5: stand-alone improvements using carrier smoothing and SNR-based weighting to reduce measurement noise.

Figures show ENU behavior and RMS summaries for the stand-alone solutions.

GNSS processing & estimation

  • Evaluation: compared solutions across methods using ENU/LLH outputs, precision estimates, and RMS error summaries.
